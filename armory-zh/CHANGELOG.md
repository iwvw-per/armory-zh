# Changelog

## [1.0.0] - 2026-10-16

### Added
- 主界面汉化：在 `document-start` 阶段把页面语言包脚本从 `ru.js`/`vendor-ru.js` 改写为官方
  简体中文包 `zh-sg.js`/`vendor-zh-sg.js`（两者写入同一个 `window.i18n.catalog`，中文覆盖俄语）。
  覆盖菜单、拍卖、钱包、优惠券、补给箱、分类、提示语等全部 UI 文案。
- 页面元信息：`<html lang>` 设为 `zh-CN`，俄语标题替换为「兵工厂 · 战舰世界军械库」。
- 游戏术语词典：内置默认映射（货币/国家/舰船类型等），并支持从仓库 `dict.json` 在线拉取
  实现热更新；命中即替换文本节点，失败自动回退到内置词典。

## [1.1.0] - 2026-10-16

### Added
- **目录即词典**：把替换后的 `window.i18n.catalog`（俄语→中文）直接用作 DOM 替换词典，覆盖
  搜索框占位符等绕过 gettext 的硬编码串。
- **属性翻译**：翻译 `placeholder`/`title`/`aria-label`/`alt`，并监听属性变化。
- **大小写/引号归一 + 时长格式**：支持 `ГЛАВНОЕ` 这类全大写菜单，以及 `4 д. 18 ч. 30 мин.`
  → `4天18小时30分` 等动态格式。
- 扩充内置词典与 `dict.json`：覆盖左栏全部分类名、货币/国家/舰种、登录入口等。
